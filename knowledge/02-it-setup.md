# Panduan IT Setup Karyawan Baru

## Hari Pertama
1. Ambil laptop di meja IT Helpdesk (Lantai 2) dengan membawa KTP dan kartu akses sementara.
2. Login pertama memakai akun sementara dari email HR: `username@majujaya.example`.
3. Wajib ganti password saat login pertama (minimal 12 karakter, kombinasi huruf besar, kecil, angka, simbol).

## Email & Kalender
- Webmail: mail.majujaya.example
- Aktifkan MFA (Multi-Factor Authentication) lewat aplikasi Authenticator dalam 24 jam pertama.
- Kalender tim sudah otomatis dibagikan oleh manager.

## VPN
1. Install aplikasi "MajuVPN" dari Self Service Portal (portal.majujaya.example).
2. Login dengan akun perusahaan + kode MFA.
3. Pilih server "ID-Jakarta". VPN wajib aktif saat WFH.
4. Jika gagal tersambung, restart aplikasi lalu hubungi IT Helpdesk.

## Software Standar
- Komunikasi: Slack (#general, #newcomers, #it-help)
- Dokumen: Google Workspace
- Manajemen tugas: Jira
- Kode: GitHub Enterprise (khusus tim Engineering; akses diminta lewat tiket Jira "IT-ACCESS")

## Keamanan
- Jangan membagikan password ke siapa pun, termasuk IT.
- Kunci layar (Win+L / Cmd+Ctrl+Q) saat meninggalkan meja.
- Laporkan email mencurigakan ke helpdesk@majujaya.example.
